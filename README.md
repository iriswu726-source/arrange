# ARTALE 多角色背包整理工具

一個純前端的小工具，用來整理 ARTALE 多個角色的背包內容：記錄每個角色有什麼、跨角色搜尋道具，也能從遊戲截圖辨識背包。

**不用安裝**：下載專案後直接用瀏覽器（Chrome / Edge / Firefox）開啟 `index.html` 即可。資料只存在你自己瀏覽器的 localStorage，不會上傳到任何地方。

## 功能

### 多角色 × 五個背包分頁
- 左側新增、改名、排序、刪除角色，可填職業、等級。
- 每個角色都有 **裝備 / 消耗 / 裝飾 / 其他 / 特殊** 五個分頁。
- 手動加入道具（名稱有自動完成），同名同備註會自動合併數量。
- 表格內直接修改名稱、數量、備註；可依名稱或數量排序。
- **⇄ 移動**：把道具（全部或部分數量）移到另一個角色，方便集中整理。

### 搜尋
- 上方搜尋列可搜尋所有角色的所有分頁（`Ctrl+F` 快速聚焦）。
- 支援空白分隔多個關鍵字（AND）、搜尋備註、簡體字（`红色药水` 找得到 `紅色藥水`）、全形英數。
- 結果依道具分組，顯示合計數量與每個角色各有多少，點一下就跳到該角色的背包。
- 可限定分頁、限定角色。
- 不輸入關鍵字時顯示**總覽**：各角色各分頁的格數，以及「同一道具分散在多個角色」的整理建議。

### 掃圖（截圖辨識）
1. 選角色與分頁，把背包截圖**拖曳進來、`Ctrl+V` 貼上**或選檔案。
2. 在圖上拖曳，框出所有道具格的範圍，設定欄數 × 列數（設定會記住，下次同尺寸截圖可直接辨識）。
3. 按「開始辨識」：
   - 自動略過空格。
   - **圖示**：與圖示庫比對；第一次看到的圖示填一次名稱並勾「記住」，之後就會自動認出來。填好一格後，其他相同圖示的格子會自動帶入名稱。
   - **數量**：用學過的「數字模板」讀取遊戲的點陣數字；還沒學過的數字可用 OCR（Tesseract.js，首次需連網下載）輔助，或直接手動輸入。寫入時確認過的數量會被學起來，之後越掃越準。
4. 檢查結果後選「加入」（加總到現有道具）或「取代分頁」（整個分頁換成掃描結果）。

> 小技巧：用遊戲內截圖或 Win+Shift+S 擷取背包視窗，**不要縮放**圖片，辨識最準。不想用自己的截圖時，可按「示範圖片」先試玩整個流程。

### 圖示庫
- 查看所有學過的圖示，可改名、指定分頁或刪除（認錯時刪掉重新學）。
- 顯示已學會的數字模板，可重設。

### 備份
- 「匯出」下載 JSON 備份（含角色、道具、圖示庫、數字模板）；「匯入」還原。換電腦或換瀏覽器時用這個搬資料。

## 開發

```bash
npm test     # 單元測試（Node 18+，無相依套件）
npm start    # 以本機 http server 開啟（非必要，直接開 index.html 也可以）
```

| 檔案 | 說明 |
| --- | --- |
| `index.html`, `css/style.css` | 頁面與樣式 |
| `js/store.js` | 資料模型：角色、分頁、道具、圖示庫，localStorage 存取 |
| `js/search.js` | 跨角色搜尋、統計、分散道具分析 |
| `js/scanner.js` | 掃圖核心：切格、空格判斷、圖示特徵比對、數字遮罩與模板學習 |
| `js/app.js` | 介面與互動 |
| `tests/` | `node:test` 單元測試 |

所有 JS 都是一般 script（不是 ES module），所以用 `file://` 直接開啟也能運作。
